# 两人食 · 情侣私享点餐小站

在文件管理器中双击 `index.html`，用 Chrome 或 Edge 打开。页面、样式和菜品图片随项目一起保存，可以离线使用。

| 身份 | 账号 | 本地密码 |
| --- | --- | --- |
| 点菜人 | `customer` | `123456` |
| 厨师 | `chef` | `654321` |

## 本地使用

在同一个浏览器的同一用户配置中，用两个标签页打开同一个 `index.html`，分别登录点菜人和厨师。点菜人可以从菜单或幸运转盘加购，填写单品和整单备注。厨师可在订单管理中更新制作进度，已完成和取消的订单会移入历史订单。两个标签页之间会同步订单和菜品变更。

菜单修改、购物车和订单保存在本机浏览器中。请保留同一个访问地址，移动文件、切换浏览器用户配置或清理站点数据都会影响对已有记录的访问。如果浏览器限制直接打开文件时的本地存储，可以在项目目录用 Python 启动仅本机可访问的服务：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后在两个标签页都访问 `http://127.0.0.1:8765/`。这个地址有独立的浏览器存储。命令窗口中按 `Ctrl+C` 可结束服务。

## 调整菜单和外观

- 在厨师后台添加菜品、修改参考价格、上传图片或上下架。
- 如需调整初始菜单或本地预置账号，编辑 `data.js`。
- 如需调整配色，编辑 `styles.css` 顶部的颜色变量。

直接打开文件时，角色检查和数据存储在浏览器内运行。两个设备共享菜单和订单时，请使用下面的服务器版。

## 服务器版与 Render

服务器版沿用「拾知」线上服务的 Aiven MySQL。点餐站是独立的 Web Service，只使用 `kitchen_` 开头的表。线上账号为点菜人 `ryj` 和厨师 `chef`，密码在 Render 环境变量中设置。`ryj` 可以查看原 `customer` 账号的订单。首次启动会初始化八道预置菜；直接打开文件所产生的浏览器数据留在本机。

1. 将本项目推送到私有 GitHub 仓库，授权 Render 读取该仓库。
2. 在 `dreamStudy` 所在的 Render 工作区新建 Blueprint，选择本项目仓库及根目录 `render.yaml`。六项数据库变量均引用控制台里名为 `dreamStudy` 的现有服务。
3. 按 Render 提示为点菜人和厨师分别设置至少 12 字符且不同的密码。会话密钥由 Render 生成。数据库的主机、端口、用户、密码、库名和 CA 证书通过 Blueprint 引用，GitHub 上只保存变量名。
4. 部署成功后打开 Render 分配的 HTTPS 地址。用两台设备，或同一台设备的两个浏览器配置，分别登录验证下单和状态同步。`/healthz` 用于验证服务和数据库连接。

本地开发服务器版需要 Node.js 22 和 MySQL 8。将 `.env.example` 复制为 `.env` 并填写本地连接和账号配置，再运行 `npm ci`、`npm start`。本地浏览器访问 `http://127.0.0.1:3001/`。
